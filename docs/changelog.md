# Changelog

The development history below uses focused `0.x` iterations. The `0.1.x`–`0.19.x` history was reconstructed on 2026-11-20; the `0.20.1`–`0.20.6` correction groups were assigned on 2026-11-22 to this same local working tree. They are scope milestones, not evidence of six historical commits, packages or releases. Original tags and published versions, including mainline `v0.3.0`, remain in the [version archive](version-history.md).

Each minor iteration introduces a workflow; patch iterations group related corrections. Dates on local milestones record the reconstruction or work snapshot, not a publication date. New uncompleted work stays in `Unreleased`. This follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) without inventing release history.

## [0.24.0] - 2026-11-27

Unified `gemini-web-mcp` entrypoint, 8 verb-object MCP tools, `ask-gemini` multimodal merge, `check-quota` (5h & weekly credits), MCP progress heartbeats, and default-on Task auto-approval across interactive cards (`0.24.0`).

### Changed

- Unified `[project.scripts]` to `gemini-web-mcp` and `gemini-web-cli`, purging legacy `gemini-mcp-*` entrypoints (`pyproject.toml`, `scripts/update_local_mcp.py`, `src/onboarding.py`).
- Renamed tools to 8 verb-object identifiers (`ask-gemini`, `generate-image`, `generate-video`, `generate-music`, `run-research`, `run-task`, `get-operation`, `check-quota`), merged `understand` into `ask-gemini(inputs=...)`, streamlined `ask-gemini` / `generate-*` parameters, and wired MCP `notifications/progress` + default wait loops into `run-task` and `run-research`.
- Added `check-quota` backed by `GRPC.GET_USAGE_INFO` (`src/services/quota.py`) reporting both exact remaining/total credits and usage percentages for 5h and weekly windows.
- Enabled Task confirmation auto-approval by default for all interactive cards and tasks regardless of origin (`src/services/task_inputs.py`, `src/infrastructure/task_confirmation.py`, `src/services/web_task_approvals.py`, `src/data/task_card_approval.js`).

## [0.23.0] - 2026-11-26

Lean 8-tool unprefixed MCP surface, live Gemini 4 + `medium` thinking defaults, IDE-agnostic rate-limit guidance, music synthesis failure fixes, and ~49% schema token reduction (`0.23.0`).

### Changed

- Simplified `gemini-mcp-function` to 8 unprefixed tools (`ask`, `understand`, `image`, `video`, `music`, `research`, `task`, `operation`), unifying image generation/editing into `image` and status/result polling into `operation`, while hiding internal media engine selectors from Agent schemas.

- Rewrote rate-limit reset guidance (`src/services/resilience.py`) and skills to be IDE-agnostic (no host-specific `/schedule` hardcoding).

### Fixed

- Fixed native music text-blueprint / `CAPABILITY_UNAVAILABLE` failures by forcing `low` thinking on `music`, detecting observed text-only refusal/blueprint replies (`src/constants.py`, `src/data/native_media_browser.js`, `src/services/media_jobs.py`), adding music-specific `ARTIFACT_NOT_RETURNED` guidance (`src/services/operations.py`), and wiring mode-21 companion options (`src/thinking_client.py`).
