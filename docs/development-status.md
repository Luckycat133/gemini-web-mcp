## Implemented products

One distribution ships three focused servers and four Runtime Skills, plus the
repository development Skill. Primary and eleven-tool compact servers remain
supported compatibility surfaces over the same services.

| Product | Runtime Skill | Entrypoint | Catalog |
| --- | --- | --- | --- |
| Assistance / understanding | `gemini-assist` | `gemini-mcp-assist` | 5 tools |
| Image / video / music creation | `gemini-create` | `gemini-mcp-create` | 7 tools |
| Explicit account management | `gemini-account` | `gemini-mcp-account` | 7 facades |
| Compatibility routing | `gemini-web-mcp` | primary / compact | profile-based / 11 tools |

Shared services own creation, typed results, Artifact verification, mixed-input
understanding, grounded search, Research, history, Notebooks/sources, Scheduled,
native Skills, Library assets, public sharing, Canvas, Gems, Prompts and cleanup.
Account facades use action-specific schemas. Mutations require independently
observed fields or absence; acknowledgement and partial coverage do not prove
completion.

Video/music start asynchronously. Research keeps its five-tool assistance
catalog through explicit start/status/result/cancel actions. SQLite provides
opaque handles, idempotent starts, credential-scoped restart/cross-client
recovery, renewable leases and seven-day operation retention. Saved Artifact
locators are persisted before automatic source deletion. Prompts, Cookies,
chat/report contents, raw responses and generated bytes are excluded from the
state store. [Recovery and cleanup](operations-and-cleanup.md) documents the
credential lineage and cancellation boundaries.
