# Development Status and Next Steps

Updated: 2026-09-27

The active package and Skill metadata remain `0.2.1`. Changes after the existing `v0.2.1` tag are recorded under **Unreleased**; neither `v0.2.0` nor `v0.2.1` is rewritten.

## Current Runtime

The repository currently ships a profile-based primary MCP server, a fixed eleven-tool low-token server, the dedicated five-tool `gemini_assist_mcp` assistance server, and two Runtime Skills: the compatibility `gemini-web-mcp` Skill and the dedicated `gemini-assist` Skill. Shared services already cover chat/session lifecycle, Artifacts, grounded search, mixed-input understanding, Deep Research starts, typed history, account workflows, packaging, protocol compatibility, and bounded live diagnostics.

The compatibility Runtime Skill is now task-first: it routes second opinion/search/understanding/Research, creation, or explicit account work without requiring a manifest call before every known workflow. Generated Artifacts are intended for downstream agent use, not merely path reporting.

## Settled Product Architecture

One repository and Python distribution will expose three focused products:

| Product | Skill | Entrypoint | MCP name |
| --- | --- | --- | --- |
| Assistance and understanding | `gemini-assist` | `gemini-mcp-assist` | `gemini_assist_mcp` |
| Multimodal creation | `gemini-create` | `gemini-mcp-create` | `gemini_create_mcp` |
| Explicit account management | `gemini-account` | `gemini-mcp-account` | `gemini_account_mcp` |

Public tools use `gemini_` prefixes. `gemini_ask` remains distinct. Deep Research starts asynchronously. The planned long-operation and cleanup recovery layer will use local-only SQLite with opaque explicit handles, seven-day default operation retention, restart/cross-client resume, and no persisted prompts, chat/report text, Cookies, raw responses, or generated bytes. That layer is not implemented yet; current Research IDs are correlation IDs without status/result/cancel tools.

The broad and low-token servers remain compatibility surfaces while the create and account products are implemented.
